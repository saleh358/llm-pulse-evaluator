# llm-pulse-evaluator
Full-stack LLM Evaluation &amp; Classification Platform built with React.js + Redux Toolkit (RTK) and ASP.NET Core 8 Vertical Slice Architecture + MediatR


## Setup Instructions

### 1. Clone the repository
```bash
git clone https://github.com/saleh358/llm-pulse-evaluator
cd llm-pulse-evaluator
```

### 2. Scaffold the project structure
```bash
python3 scaffold.py
```

### 3. Launch Backend
```bash
cd backend/LlmPulse.Api
dotnet run --urls "http://localhost:5080"
```

### 4. Launch Frontend
```bash
cd frontend
npm install
npm run dev
```
